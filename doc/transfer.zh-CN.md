## 上传与文件接口

后端接口统一使用 `/api` 前缀。

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| POST | `/api/upload/init` | 初始化上传 |
| POST | `/api/upload/chunk` | 上传分块 |
| GET | `/api/upload/status/:session_id` | 查询上传进度 |
| POST | `/api/upload/complete` | 完成上传 |
| POST | `/api/upload/cancel` | 取消上传 |
| GET | `/api/files` | 获取文件列表 |
| GET | `/api/files/*filename` | 下载文件，支持 Range 请求 |
| DELETE | `/api/files/*filename` | 删除文件 |
| GET | `/api/disk-info` | 获取磁盘信息 |

文件名作为 URL 路径参数时需要编码。

文件列表的 `mtime` 使用包含时区的 RFC3339 时间，前端按查看者的本地时区和界面语言展示；排序依据实际时间。

文件列表每次请求完成后等待 3 秒自动检查变化，磁盘信息独立每 15 秒更新；保留搜索、排序和分页状态。确认删除、删除请求及预览（含编辑）期间暂停，选中文本时跳过更新；页面隐藏时取消后台请求，重新显示后立即更新。失败时各自保留当前数据并在下轮重试，不打断操作错误提示；手动刷新和删除、编辑成功后立即刷新两者。后台请求不显示整页加载状态。

`GET /api/files?view=list` 只返回文件清单及总大小，提供 ETag；后台更新发送 `If-None-Match`，未变化返回无正文的 `304`。只有实际接受响应时才保存版本，取消的响应不会污染缓存；手动刷新强制获取完整列表。服务端缓存序列化结果，未变化的扫描复用原快照；上传、编辑和删除立即使缓存失效，服务外部变更沿用 2 秒扫描缓存期限。磁盘变化不影响清单 ETag。

`GET /api/disk-info` 独立返回容量、已用、可用空间以及 `disk_pct`、`disk_pct_warning`。原始 `GET /api/files` 继续返回包含磁盘信息的完整响应以兼容已有客户端，且不提供清单专用的 ETag。两类响应均设置 `Cache-Control: no-store`。

### 文件预览

文件列表中的“预览”在当前页面打开弹窗，支持图片、UTF-8 文本、PDF 及浏览器支持的音视频；关闭或按 Esc 返回列表。手机使用全屏窗口。PDF 或媒体格式无法显示时可下载查看。

剪贴板图片也使用相同的预览弹窗，查看期间暂停自动更新，关闭后恢复。

`GET /api/files/*filename?preview=info` 返回 `kind`、`mime_type` 和 `text`；`kind` 为 `text`、`image`、`pdf`、`audio` 或 `video`，仅文本类型包含正文。文本最多 1 MiB，超限返回 413，不支持的类型或编码返回 415。HTML、SVG 和代码按纯文本展示，不执行内容。

`GET /api/files/*filename?preview=1` 内联返回受支持的文件，支持 Range 请求。预览复用文件下载的访问验证和路径检查；普通下载行为保持不变。预览响应禁止缓存。

### 文本编辑

文本预览提供“编辑”“保存”“取消编辑”。关闭、取消或重新加载时若有未保存的修改，会要求确认放弃；保存失败时保留草稿。保存成功后刷新文件列表的大小和时间。

浏览器后退、前进和站内跳转也会拦截未保存的编辑，允许继续编辑或确认放弃；正在保存时等待请求完成。会话失效后草稿在当前页面内存中保留，重新解锁并回到文件列表后自动恢复编辑，沿用原版本进行冲突检查。草稿不会写入浏览器持久存储；刷新、关闭页面前仍会提示未保存修改。

`GET /api/files/*filename?preview=info` 的文本结果还包含 `version`。使用 `PUT /api/files/*filename`，JSON 为 `{"text":"新内容","version":"预览返回的版本"}`，保存成功返回新 `version`。必须使用原版本：缺失返回 428，文件内容已改变返回 409，文件已删除返回 404。冲突后保留草稿，可复制所需内容再重新加载，不提供强制覆盖。

仅支持上述文本类型和 UTF-8，保存后的文件最大 1 MiB（包含 BOM 和换行）。保留原文件的 UTF-8 BOM 和权限位；编辑器统一使用 LF，保存时采用原文件首次出现的换行风格（LF、CRLF 或 CR）。内容未变时保留原始字节，包括混合换行。通过同目录临时文件写入并同步后替换原文件，不直接截断原文件；版本检查与服务内的编辑、删除串行执行。不要让多个服务进程同时编辑同一数据目录，服务外部写入也应避开保存过程。

编辑沿用共享访问权限：所有已解锁访问者均可修改文件。启用访问口令时，PUT 请求也执行会话与同源检查。

## 剪贴板接口

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/clipboard` | 获取最新记录，返回 `entries` 数组 |
| POST | `/api/clipboard` | 发布文本，JSON 请求体为 `{"text":"共享内容"}` |
| DELETE | `/api/clipboard/:id` | 删除单条记录 |
| DELETE | `/api/clipboard` | 清空全部记录 |
| GET | `/api/clipboard/image-config` | 获取图片开关及实际限额 |
| POST | `/api/clipboard/image` | 以 multipart 字段 `image` 发布一张 PNG/JPEG |
| GET | `/api/clipboard/:id/image` | 获取原始 PNG；`?download=1` 下载，`?thumbnail=1` 获取缩略图 |

发布成功返回创建的记录。记录包含 `id` 和 `created_at`，`type` 标识记录类型，兼容旧数据时缺省值按文本处理。文本记录包含 `text`，图片记录包含 `image` 元数据。文本以纯文本处理，单条最多 65,536 个 UTF-8 字节；文本和图片合计保留最近 100 条。

剪贴板响应使用 `Cache-Control: no-store`。列表提供 `ETag`，使用 `If-None-Match` 可在内容未变时获得无正文的 `304`；内容变化时返回完整列表。

图片限额、解码并发和存储恢复规则见[配置说明](configuration.zh-CN.md#图片剪贴板)。

列表使用最长边不超过 320 像素的 PNG 缩略图，复制和下载仍使用原图。缩略图缓存在内存中，随记录删除或淘汰而释放；重启后首次访问时重建，无需单独备份。

## 上传流程

1. 调用初始化接口，传入文件名、大小和可选的 `relative_path`，取得会话、分块大小及传输方式。
2. 按返回的分块大小上传。`upload_transport: "raw"` 表示使用 `application/octet-stream` 请求体；未声明该能力时使用 multipart。服务端也兼容 multipart 客户端。
3. 全部分块上传后调用完成接口，服务端校验大小和分块完整性后保存文件；取消任务调用取消接口。

前端对网络故障和临时服务错误最多重试两次，使用退避等待并遵守 `Retry-After`；等待超过 60 秒时停止自动重试。无效请求、存储权限、只读或容量不足等错误直接提示，取消会立即中止重试等待。

完成接口可安全重试：服务端最多保留 4096 条完成结果，有效期最长 1 小时，不保留临时文件或分块映射。重复完成或查询上传状态会返回原保存文件名、大小及 `status: "success"`。结果记录的是原上传成功，即使文件随后被删除，也不会重新创建文件；服务重启会清空结果。前端完成请求在服务端同步文件时不设超时，遇到临时错误先查询状态再重试完成。仍无法确认时，手动重试沿用原会话，不会重新上传；结果过期或服务重启后，请先检查文件列表，再决定是否重新上传。

文件夹上传通过 `relative_path` 保留顶层目录及子目录，例如 `资料/照片/图片.jpg`。文件列表、下载和删除使用相对于上传目录的路径，URL 路径参数需要编码。空文件夹不保存，同名冲突自动改名，不覆盖已有内容。

## 限制与错误

| 项目 | 限制或行为 |
| --- | --- |
| 默认传输参数 | 8 MiB 分块；前端每个文件 3 路并发，同时处理 2 个文件 |
| 单文件大小 | 最大 1 TiB |
| 上传 JSON | 初始化请求体最多 64 KiB，原始文件名最多 4096 个 UTF-8 字节；完成和取消请求体最多 1 KiB，会话 ID 必须为标准 UUID |
| 服务端容量 | 最多同时接收 16 个块，保留 1024 个活跃会话；超限返回 429 |
| 相对路径 | 最多 32 层、4096 字节；每段清洗后最多 200 个 UTF-8 字节，含扩展名及冲突后缀 |
| 路径校验 | 拒绝绝对路径、目录穿越和符号链接；无效路径返回 400，父路径冲突返回 409 |
| 存储要求 | 临时目录与上传目录位于同一个支持硬链接的文件系统 |
| 磁盘检查 | 初始化检查可用空间，但不预留容量，并发上传仍可能耗尽空间 |
| 存储错误 | 空间或配额不足返回 507，权限不足返回 403，只读文件系统返回 503 |
| 会话过期 | 每 5 分钟清理闲置超过 24 小时的会话，正在写入的会话除外 |
| 空上传目录 | 初始化失败、取消、过期和删除文件时，回收本服务创建的空祖先目录；保留预先存在的目录和其他活跃上传使用的目录 |
| 重启与续传 | 会话保存在内存；重启清空临时上传，不支持重启后的续传 |
| 下载 | 支持 Range 请求；文件、预览和剪贴板图片共用 32 个并发响应名额，满额返回 429。每次写入设置 30 秒空闲超时，随发送进度刷新，不限制总传输时长 |
| 文件列表缓存 | 文件清单、数量和总大小缓存 2 秒，上传完成或删除后立即失效；外部文件变更在过期后反映，磁盘可用空间仍实时查询 |

请求失败时可通过响应头 `X-Request-ID` 查找服务端日志，详见[日志排错](logging.zh-CN.md#排错步骤)。
